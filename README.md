# Mingle — Event ticketing for good times

A responsive, Kenya-focused event discovery and ticketing marketplace prototype built with React, TypeScript, and Vite. Explore Nairobi events, browse categories, view event details, choose a ticket quantity, save favourites, and preview attendee, organizer, and admin dashboards.

## Getting started

1. Install Node.js 20.19+ or 22.12+.
2. In this project folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.
4. Run `npm run build` to type-check and create a production build.

## Prototype scope

All event and dashboard information is sample data. Checkout, authentication, QR scanning, payment processing, refunds, notifications, and event moderation are demonstration interactions only; no real payments or account data are processed. Connect trusted server-side services before using this for live ticket sales. Event artwork is made with CSS illustration rather than downloaded images.

## Main views

- **Discover:** Search and filter upcoming events, open event details, choose a sample ticket quantity, and save events.
- **My tickets:** Sample attendee ticket passes with demonstration QR artwork.
- **For organizers:** Sample sales summary, event list, quick actions, and check-in preview.
- **Admin:** Sample platform metrics and event review queue.
